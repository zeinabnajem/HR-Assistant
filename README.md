# 💬 AI HR Assistant (Tool-Calling Agent)

> An intelligent AI-powered HR assistant built using LangChain + Google Gemini + Tool Calling Agents.

---

## 🎯 Project Goal

The goal of this project is to demonstrate:

- Building AI Agents using tool calling
- Integrating LLMs (Google Gemini) into real applications
- Connecting AI with structured HR data
- Creating intelligent decision-based systems

---

## 🚀 Project Overview

It allows users to interact naturally with an AI that can:
- Retrieve employee details
- Check leave balances
- Generate interview questions using AI

The system uses a **tool-calling agent architecture**, meaning the AI automatically decides which tool to use based on the user’s request.

---

## 📝 Note

This project uses **mock data** for employees and leave balances.

No real employee information is used. All data is generated for demonstration and educational purposes only.
